# B站视频 BGM 识别

输入 B 站视频的 BV / AV 号和时间区间，自动识别这一段用的是什么背景音乐（BGM）。区间内若被解说 / 对话盖住，会自动去人声后再识别一次。

## 如何使用

1. 打开网页应用。
2. 填写 **视频 BV 号 / AV 号**，支持以下形式：
   - `BV16dJv6nEJH`（完整 BV 号）
   - `AV123456` 或纯数字 `123456`（AV 号）
3. 填写 **起始时间** 和 **结束时间**，支持以下格式：
   - `1:30` → 1 分 30 秒
   - `90` → 90 秒
   - `1分30秒` → 1 分 30 秒
4. （可选）**「被解说 / 对话盖住时自动去人声」**：默认勾选。开启后，若直接识别失败，会自动分离人声、用伴奏再识别一次。
5. 点击 **「开始识别」**，稍等片刻即可看到结果。

## 结果说明

- **识别成功**：显示歌名与歌手，并标注是否启用了「自动去人声」。
- **识别失败**：提示「未识别到匹配的 BGM」。可尝试调整时间区间、缩短片段，或确认该段是否确实有可识别的 BGM。

> 想听 / 验证识别出的歌曲？把歌名复制到 **网易云音乐 / QQ音乐 / B站** 搜索通常更快——尤其对 DJ 变调版、二次创作类 BGM，国内曲库的文字搜索比 Shazam 更准。

## 已知限制

- **曲库覆盖**：识别基于 Shazam，其曲库偏欧美流行，对动漫、国创、DJ remix、二次创作等 BGM 覆盖相对较弱，可能识别不到。
- **人声遮挡**：当原视频该区间人声（解说 / 对话）很重、明显盖过 BGM 时，即便自动去人声也可能无法识别。
- **冷门 / 纯音乐**：冷门或非常小众的 BGM 可能不在曲库中。
- **网络与限流**：识别依赖 B 站视频可访问与 Shazam 服务可用；网络不佳或遇 B 站限流时可能下载 / 识别失败，可重试。
- **结果偏差**：识别结果来自 Shazam 匹配，歌名 / 歌手以 Shazam 数据为准，二次创作版本可能与实际有出入。
- **区间长度**：过长区间可能导致识别变慢或失败，建议截取较短片段（如 30 秒以内）以提高成功率。
